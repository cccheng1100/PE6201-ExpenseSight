# Development Data

The 22 development cases are separate from the 50 candidate holdout cases.
They may be used to write prompts, inspect failures, and change the system.

Development distribution:

- 6 clean or hard-negative cases;
- 10 warning-review cases;
- 6 deterministic return cases;
- 5 complex multi-leg cases;
- 3 explicit task-scoped abstention targets embedded in warning cases.

This is a debugging distribution, not an estimate of real-world prevalence.
Claims and annotations are generated by separate scripts and stored separately.
